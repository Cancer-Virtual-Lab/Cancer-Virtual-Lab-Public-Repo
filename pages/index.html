Real-world oncology data, ready for research.

The Cancer Virtual Lab standardises clinical records as HL7 FHIR resources and connects them in a knowledge graph governed by a domain ontology, so researchers can select cohorts, run analytics and ask questions in natural language.

How it works

From the clinical record to a question answered

Each step uses open standards, so the data stay interoperable outside the platform.

01

Clinical records

Diagnoses, therapies, administrations, adverse events, biomarkers and laboratory tests from IRST systems.

02

HL7 FHIR

Mapping rules convert each table into FHIR resources that conform to 19 CVL profiles.

03

Knowledge graph

Resources become RDF typed with cvl: classes and linked to SNOMED CT, LOINC and NCIt.

04

Research

Reasoning, cohort selection, analytics and natural-language queries on the same graph.
